# Fynske Havørredture

En statisk fiskeblog til `madsfinseth.com` med fortællinger og billeder fra havørredture på Fyn. Siden indeholder tre visuelle temaer – Morgentur, Dagtur og Aftentur – samt separate tursider med billedgalleri og lightbox.

## Seneste ændringer

- Tilføjet fisketurene Tårup og Nordskov som separate sider.
- Gjort billederne på forsiden ensartede og mere kompakte.
- Tilføjet mindre galleribilleder på tursiderne med visning i fuld størrelse ved klik.
- Rettet Aftentur-temaets mørke baggrund, skrifttyper, tekstfarver og billedfarver.
- Fjernet den hvide bjælke i toppen af Aftentur-temaet.
- Tilføjet denne README og fjernet den tidligere uploadvejledning.

## Udgivelse

Pak ZIP-filen ud, og upload hele indholdet til webmappen på webhotellet. `index.html` skal ligge direkte i webmappen.

Ved kommende opdateringer udskiftes hjemmesidens eksisterende filer med filerne fra den nyeste pakke.
